The Audit Logs module shall allow Organization Admins to:

View activity logs generated within the organization.

Search audit records.

Filter audit records by user, action, module, and date range.

Export audit logs.

Monitor user activities and system events.

Support compliance and security investigations.

Flow

User clicks Audit Logs from the side menu.

Audit Logs screen opens.

System loads audit records.

User may search logs.

User may apply filters.

User may export logs.

Column Definitions

Timestamp 

Date and Time when action occurred. 

Example: 15-Jun-2026 10:45 AM 

Actor 

User who performed the action. 

Example: John Smith 

Action 

Action performed by the user. 

Supported Values: 

Created 

Updated 

Deleted 

Login 

Module 

Portal module where activity occurred. 

Examples: 

Team Management

Provider Management

Patient Management

IP Address 

IP Address of the user who performed the action. 

Example: 192.168.1.100 

Details 

Short descriptive message of the activity.

Examples:

Provider "John Smith" created successfully.

Patient "PAT-10024" updated.

User logged into portal.

Team user deleted successfully.

Business Rules

Capture user activities in real-time.

Store audit records securely.

Track user accountability.

Support compliance investigations.

Maintain historical activity records.

Allow filtered retrieval of audit events.

Generate export-ready audit reports.
